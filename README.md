# EDIPE_shinyapp
The European Diatom Inventory for Palaeoecology and Ecology (EDIPE) is a a curated bibliographic resource of diatom studies encompassing modern ecological surveys, surface sediments, top-bottom samples, and sediment core records. This R shiny app allows users to query the inventory via filtering and visualizing where the diatom collection units are and their temporal age span, as well as  associated metadata. The objetive is to enhance data discoverability, accessibility, and reuse across ecological and palaeoecological domains.
