# EDIPE_shinyapp
The European Diatom Inventory for Palaeoecology and Ecology (EDIPE) is a a curated bibliographic resource of diatom studies encompassing modern ecological surveys, surface sediments, top-bottom samples, and sediment core records. Here, we present a R shiny app to dynamically query the inventory via filtering and visualizing the diatom studies and associated metadata. The objetive is to enhance data discoverability, accessibility, and reuse across ecological and palaeoecological domains.
